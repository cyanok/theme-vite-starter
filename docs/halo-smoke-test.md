# Halo 2.26 运行时冒烟检查

本清单用于验证构建检查无法覆盖的 Thymeleaf 表达式、Finder 调用、页面样式、评论和插件布局。修改相应功能后检查受影响的项目及一个共享布局页面；发布前完整检查。

## 准备与记录

1. 使用 Halo **2.26.0** 的独立测试站检查最低兼容版本；其他目标版本分别验证。按 [快速开始](../README.md#快速开始) 安装并启用主题，执行 `pnpm build`，关闭 Thymeleaf 缓存；修改元数据或设置表单后重载主题配置。
2. 先在无公开文章时检查空状态，再准备表格中的数据。保留原有主题设置、菜单和插件状态，便于恢复。
3. 用未登录窗口访问公开页面，在桌面和移动端（含 320 像素宽度）检查实际内容与布局，并通过浏览器 Console、Network 和 Halo 日志确认没有模板错误或资源加载失败。

记录主题 commit、Halo 与插件版本，以及各项结果和失败时的 URL、复现步骤。缺少实例、数据或插件时标为“未执行”；自动化检查通过不能替代运行时结果。

## 正文宽内容检查

将 [正文示例片段](fixtures/article-content.html) 用于一篇文章和一个独立页面。使用编辑器的 HTML 模式，发布后确认正文保留 `width`、`height`、表格内联宽度和 `iframe`；被编辑器清理的内容需恢复后再测。

示例中的图片和视频封面使用内联 SVG；若编辑器不支持 `data:` 地址，上传等比例宽图替换并保留宽高。视频示例只有封面，验证播放时需上传一段 16:9 视频并设置 `video` 的 `src`。

- [ ] 图片宽度不超过正文；蓝色圆形保持正圆，图片高度随宽度等比例缩小。
- [ ] 视频宽度不超过正文，16:9 画面比例保持正常；设置有效视频地址后，播放和控件均可用。
- [ ] 1200 像素宽的表格在自己的区域内横向滚动，最右列“合计（最右列）”可见；表格仍保留表头和表格语义。
- [ ] 960 像素宽的嵌入页在自己的区域内横向滚动，右侧“嵌入内容最右侧”可见；固定高度没有因强行设置视频比例而被裁切。
- [ ] 键盘 Tab 能聚焦表格和嵌入的滚动区域，聚焦有可见轮廓，可用方向键横向滚动。
- [ ] 长代码只在代码块内横向滚动，长文本正常换行；整页不出现横向滚动，页头和页脚宽度不受正文影响。
- [ ] 文章和独立页面均加载共享脚本，桌面和移动端没有正文适配脚本错误。

正文适配脚本为 `table`、`iframe`、`object` 和 `embed` 添加局部滚动容器。实际内容使用 `object` 或 `embed` 时，也需检查资源加载和宽度。

## 评论启停检查

使用与目标 Halo 版本兼容的评论插件，准备允许评论的文章和独立页面。

1. 未安装或停用评论插件时访问两种页面：正文完整，不显示失效的评论控件，不出现模板异常或调用不存在组件的错误。
2. 启用评论插件，并在 Halo 的评论设置中允许评论：两种页面均能显示可用的评论区域。在测试站分别提交不同内容的测试评论；如果启用审核，完成审核后确认各评论只属于对应文章或独立页面，刷新后仍正确。
3. 在内容设置中关闭其中一篇文章或一个独立页面的评论，再检查对应页面按评论配置隐藏或禁止评论，其他允许评论的页面仍正常。
4. 停用插件后重访两种页面，再重新启用复查：正文和导航始终可用，评论区域随有效配置变化，不残留失效入口。

## 使用公共布局的插件页面

使用一个兼容目标 Halo 版本、明确调用 `layout :: html(head, content)` 的真实插件页面，并记录页面 URL 和模板调用依据。没有调用该契约的插件页面无法覆盖此项，没有合适插件时标为“未执行”。契约说明见 [Halo 页面布局文档](https://docs.halo.run/developer-guide/theme/page-layout)。

- [ ] 主题重载后，Console 的页面布局状态为 `SUPPORTED`；该状态只代表静态兼容，还需检查实际页面。
- [ ] 插件页面显示插件自己的正文和标题；文档只有一个有效标题，插件的头部资源也正常加载。
- [ ] 插件页面使用当前主题的站点标题、导航、页脚和共享样式，桌面与移动端均正常。
- [ ] 修改主题设置的自定义页脚，普通文章和插件页面同步生效，内容没有重复。
- [ ] Halo 页脚注入及插件需要的资源正常，浏览器 Console 和 Halo 日志没有片段解析、表达式或资源错误。
